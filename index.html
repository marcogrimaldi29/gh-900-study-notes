ⓘ Exam Format

GH-900 is a proctored, multiple-choice exam (roughly 40–60 questions) priced at $99 USD. A score of 700 or greater (on a scale to 1000) is required to pass. It is aimed at non-developers, developers, and all GitHub users — no coding is required. You can explore the interface ahead of time with the exam sandbox and try the free practice assessment. If the exam is not available in your preferred language, you may request an additional 30 minutes.

⚠ Exam Updated — January 2026

The GH-900 objectives changed significantly in January 2026: new objectives were added, some were removed or reworded, and several moved between functional groups. These notes follow the current seven-domain structure. Always cross-check the official study guide for the latest change log.

Version control fundamentals, Git vs. GitHub, repositories, commits, branches, accounts, GitHub Flow, Markdown, Desktop & Mobile.

Repository structure and key files, templates and branches, managing files, insights, stars, metrics dashboards, and maintenance.

Issues, pull requests, and discussions; linking PRs to issues; templates, filters, assignments; notifications; Gists, Wikis, and Pages.

10-15%

Apply Modern Development Practices

GitHub Actions, Copilot (agents, Agent Mode, multi-model), Copilot plans, Codespaces & dev containers, and github.dev.

10-15%

Manage Projects with GitHub

GitHub Projects and layouts, labels, milestones, workflows, saved replies, assignees, and project insights.

5-10%

2FA and passkeys, permissions and roles, Enterprise Managed Users, org Copilot policy, visibility, branch protection, teams.
